# Evaluación 2 Backend

## Descripción del proyecto

Proyecto desarrollado con Django. Consiste en una página web de películas organizadas en tres géneros: Acción, Comedia y Drama.

Cada género contiene 10 películas con su nombre, año, imagen y descripción. La página utiliza Bootstrap para el diseño y permite navegar entre las diferentes secciones.

## Tecnologías utilizadas

- Python
- Django
- HTML
- CSS
- Bootstrap
- Git y GitHub
